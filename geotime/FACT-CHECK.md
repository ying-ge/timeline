# geotime 时间线内容校对规范

> 依据 2025 年对本页 32 条事件（d 字段）与 32 条八卦（gossip）的逐条 Wikipedia 对照核查整理。
> 供后续新增/修订条目使用：**写作时预防，提交前逐项核对。**

## 一、已发生过的错误类型（前车之鉴）

| # | 错误类型 | 实例 | 教训 |
|---|---|---|---|
| 1 | **旧估计数字** | 石炭纪含氧量写"约35%"，Wikipedia 现文为峰值 25–30%（有波动） | 百分比、速率类数字要查条目**当前**表述，不凭记忆（教材/科普书里的数字常滞后） |
| 2 | **统计口径混用** | 二叠纪末"81%–96%的海洋物种"：81% 是海洋物种、96% 是另一统计（属/科口径） | 区分 物种/属/科、海洋/陆地/全部、灭绝率/消失率。区间两端必须同口径 |
| 3 | **单一数字掩盖分群差异** | 三叠纪末"约76%物种消失"是旧的总估计；现文按类群：23–34% 海洋属、42% 陆地四足类、96% 珊瑚属 | 大灭绝损失差异极大，优先按类群/相（海/陆）分列，或取条目主推数字 |
| 4 | **速率单位/主体混淆** | "印度板块每年约5厘米"易被读成"喜马拉雅每年长5厘米"（实际山脉抬升约5 mm/yr） | 速率必须写清**主体**（板块汇聚 vs 山体抬升）与单位；数量级换算自查一遍（cm↔mm 差10倍） |
| 5 | **署名遗漏** | Tiktaalik 只写 Shubin，实为 Daeschler、Shubin、Jenkins 三人团队 | 科学发现写全关键人物；相反情形也要写：Miller–Urey 论文实为 Miller 独自署名（Urey 拒绝署名）——团队简称≠论文作者 |
| 6 | **重定向/消歧义链接** | `Domain_(biology)` 括号丢失落到 `Domain#Science` 空页；`Ammonite`→`Ammonoidea`、`Homo_sapiens`→`Human` 等重定向 | 见 §四 链接检查流程 |
| 7 | **英文残留笔误** | 八卦正文残留 "ironically:"、"inherited" | 中文正文提交前 grep 一遍残留英文单词 |
| 8 | **不可考细节** | "Miller 在 Urey 家聚会获得灵感"查无出处，已删 | 轶事必须能在来源条目找到对应原文；找不到就删，不硬凑趣味 |

## 二、数字类条目写作规则

1. **来源优先级**：事件链接指向的 Wikipedia 条目 > ICS 时间轴（年代界线）。核查数字时以条目**正文**为准，infobox 与正文冲突时用正文。
2. **区间两端同口径**（错误类型 2）。写"约 X%"时注明对象："约85%的**海洋物种**"。
3. **年代界线用 ICS v2023/09**：如寒武纪底界 538.8 Ma、二叠纪末 251.9 Ma、K-Pg 66 Ma。跨期事件写区间（"约3.72–3.59亿年前"），不确定的标"约""（不确定）""（有争议）"。
4. **旧估计 vs 现行值**：若历史上有著名旧值（如含氧 35%、三叠纪末 76%），可写"（旧估计曾达 X%）"供教师参考，但主数字用现行值。
5. **速率**：写清主体+单位+时间尺度（"板块汇聚约5 cm/yr；山脉抬升约5 mm/yr"）。

## 三、人物/故事类条目写作规则

1. **发现者/作者**：查条目 Discoverers/Authors 段，写全关键人名；注明论文署名实情（如有单署名、拒署名等特殊情况）。
2. **发表时间线**：区分 发现年（如 Tiktaalik 2004）与 论文发表年（2006 Nature）；不能只用一个含糊的"随后"。
3. **期刊/荣誉**：期刊名用书名号或斜体惯例（Nature→《Nature》）；奖项注明年份。
4. **争议表述**：有争议的结论（如 Dunkleosteus 咬合力）用"据估计""有争议"，不写死数字。
5. **每条八卦以对应 wiki 条目可查证为底线**：写完后能指出"这句出自条目哪一段"。

## 四、wiki 链接检查流程（新增/修改链接必做）

用 MediaWiki API 验证直达性与重定向（在任一 en.wikipedia 页面控制台执行即可，无 CORS 问题）：

```js
const check = async (title) => {
  const r = await fetch('https://en.wikipedia.org/w/api.php?action=query&titles='
    + encodeURIComponent(title) + '&redirects=1&format=json');
  const q = (await r.json()).query;
  const redir = q.redirects?.[0]?.to;
  const type = await fetch('https://en.wikipedia.org/api/rest_v1/page/summary/'
    + encodeURIComponent(redir || title)).then(x => x.json()).then(j => j.type);
  console.log(title, '→', redir || '直达', '|', type);
  // type 必须是 "standard"；"disambiguation" 或 "Internal error" 都要处理
};
```

规则：
- `type === 'disambiguation'` → 改用消歧义后括号形式（URL 中括号编码为 `%28 %29`）
- 存在重定向 → 改为直达目标 URL（如 `Euprimates`→`Primate`、`Ammonite`→`Ammonoidea`），避免未来重定向变更
- `type === 'Internal error'` → 该条目损坏，找同义标题

## 五、术语规范（面向生物专业师生）

1. **保留规范术语**，首次出现附英文：古菌域（Archaea）、条带状铁矿（BIF）、标准化石（index fossil）、GSSP、K-Pg 界线、气囊系统（air sac）。
2. **不用幼儿化隐喻**替代术语：❌"私有池塘"→✅羊膜腔/羊水；❌"壳上的日记"→✅生长纹/标准化石。
3. **通俗化只用于解释，不用于替代**：可以在术语后加"（即……）"帮助理解。
4. 分类层级写准确：盾皮鱼类、辐鳍鱼/肉鳍鱼、合弓纲/蜥形类、镶嵌踝类主龙（crurotarsans，鳄类近亲）、哺乳形类、非鸟恐龙（必要时注明"除鸟类祖先外"）。
5. 人名首次出现用全名，之后可只用姓；中文名从通行译名，无通行译名保留原文。
